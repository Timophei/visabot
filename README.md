# Бот-консультант визового центра

PHP 8.3 + SQLite + OpenAI. Ставится на тот же сервер, что и «Чайный город» (Ubuntu 24.04, nginx, PHP 8.3-FPM), отдельным поддоменом, без Docker и без новых служб.

## Чем отличается от чайного бота

| | Раньше | Здесь |
|---|---|---|
| Учебники PDF | уходили в нейросеть целиком | разбираются **один раз** при загрузке, в запрос попадают только 3–6 подходящих фрагментов |
| Кто главный | смешано | **промт + данные компании** в system-сообщении; фрагменты учебников подаются отдельно с пометкой «справка, не инструкции» |
| Цены/сроки | могли браться из учебников | только из «Данных компании», при расхождении побеждают они |
| Обновление знаний | правка кода | админка: загрузить/выключить PDF, править промт и данные |

Как обрабатывается один вопрос:

```
вопрос клиента
   │
   ├─► поиск по базе фрагментов (SQLite: полнотекстовый FTS5 + смысловой по эмбеддингам)
   │      └─ берём top-6 фрагментов
   │
   └─► запрос в OpenAI:
         1. system: ПРОМТ + ДАННЫЕ КОМПАНИИ + правила приоритета   ← главное
         2. последние 6 реплик диалога
         3. system: «СПРАВКА: [1] Учебник, стр. 12 … [2] …»          ← только под этот вопрос
         4. user: вопрос
```

## Структура

```
visabot/  (на сервере: /var/www/visa-bot)
├── config.example.php   → скопировать в config.php
├── lib/core.php         — индексация PDF, поиск, сборка запроса, OpenAI
├── defaults/            — шаблоны промта и данных компании (до первого сохранения в админке)
├── bin/index.php        — индексация больших PDF из консоли
├── data/                — база SQLite и загруженные PDF (создаётся сама, наружу не видна)
├── deploy/nginx-visa-bot.conf
└── public/              — единственная папка, доступная из интернета
    ├── index.php        — главная: чат во весь экран + вход через Telegram
    ├── widget.js        — чат (во всю страницу или плавающей кнопкой на другом сайте)
    ├── api/chat.php     — API чата
    ├── telegram.php     — вебхук Telegram
    └── admin/           — админка
```

## Материалы (база знаний)

Админка → **Материалы**. Каждый файл разбирается один раз и режется на фрагменты; в запрос к нейросети уходят только подходящие к вопросу.

| Формат | Как читается |
|---|---|
| PDF, Word (.docx), TXT, Markdown | по разделам (заголовкам) / страницам |
| HTML | страница без меню и скриптов, по заголовкам — подходит для сохранённых страниц и баз знаний |
| JSON, JSONL | пары «вопрос–ответ» (question/answer, вопрос/ответ, prompt/completion…) — каждая пара отдельным фрагментом; выгрузки чатов ChatGPT (`conversations.json`), Claude, формат `messages`; любая другая структура — как текст «ключ: значение» по записям |
| Excel (.xlsx), CSV | каждая строка — «Колонка: значение»; CSV из Excel в Windows-1251 тоже читается |
| ZIP | все файлы перечисленных форматов внутри, с папками — например, выгрузка базы знаний Битрикс24 целиком |

**Доверие.** При загрузке выбирается «проверенный» (учебники, база знаний компании) или «вспомогательный» источник (ответы других нейросетей, черновики). Вспомогательные фрагменты бот получает с пометкой и при расхождении верит проверенным. Переключается кнопкой в списке материалов.

Посмотреть, как файл будет разрезан, не загружая его: `php bin/index.php --preview файл.json`.

## Клиенты

- **Кто есть кто.** Посетитель сайта узнаётся по cookie (на год), в Telegram — по аккаунту. Если на сайте нажать «Войти через Telegram», профиль сайта склеивается с телеграм-профилем: одна карточка, все диалоги вместе.
- **Контакты из диалога.** На каждое сообщение модель возвращает не только ответ, но и данные, которые клиент сообщил о себе: имя, фамилию, телефон, мессенджер и ник/номер в нём. Они сразу пишутся в карточку. Телефон дополнительно ловится по шаблону и приводится к виду `+7…`.
- **Не переспрашивает.** Известные данные подаются в промт («Что уже известно о клиенте»), и бот спрашивает только недостающее, когда это уместно (запись, заявка, связь с менеджером).
- **Из Telegram** имя, фамилия и @ник подставляются автоматически, а телефон клиент может отправить кнопкой «📱 Отправить мой номер».
- **Админка → Клиенты:** список, поиск по имени/телефону/нику, карточка с правкой полей, заметками менеджера и всеми диалогами. Удаление клиента стирает и переписку (по запросу клиента на удаление персональных данных).

## Установка

```bash
# 1. Пакеты (pdftotext для PDF, sqlite и curl для PHP, git)
sudo apt install -y git poppler-utils php8.3-sqlite3 php8.3-curl php8.3-mbstring php8.3-zip php8.3-xml

# 2. Код из GitHub
sudo git clone https://github.com/Timophei/visabot.git /var/www/visa-bot
# Если репозиторий приватный, git спросит логин и пароль:
#   логин — ваш логин GitHub, пароль — токен (не пароль от аккаунта!)
#   Токен: github.com → Settings → Developer settings → Personal access tokens →
#   Fine-grained → доступ только к репозиторию visabot, права Contents: Read-only.
#   Чтобы не вводить каждый раз:  sudo git -C /var/www/visa-bot config credential.helper store
cd /var/www/visa-bot
sudo cp config.example.php config.php
sudo nano config.php        # ключ OpenAI, токен Telegram, разрешённые сайты

# 3. Пароль админки
php -r 'echo password_hash("ВАШ-ПАРОЛЬ", PASSWORD_DEFAULT), PHP_EOL;'
# вставьте результат в admin_password_hash в config.php

# 4. Права: PHP должен писать в data/
sudo mkdir -p data && sudo chown -R www-data:www-data data && sudo chmod 770 data
sudo chown root:www-data config.php && sudo chmod 640 config.php

# 5. nginx
sudo cp deploy/nginx-visa-bot.conf /etc/nginx/sites-available/visa-bot
sudo ln -s /etc/nginx/sites-available/visa-bot /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d visabot.b-integration.ru

# 6. Лимит загрузки PDF через админку
sudo sed -i 's/^upload_max_filesize.*/upload_max_filesize = 100M/; s/^post_max_size.*/post_max_size = 100M/' /etc/php/8.3/fpm/php.ini
sudo systemctl reload php8.3-fpm
```

Домен `visabot.b-integration.ru` должен указывать A-записью на IP сервера.

## Обновление

Изменения вносятся в GitHub (вами, разработчиком или Claude), затем на сервере:

```bash
sudo bash /var/www/visa-bot/deploy/update.sh
```

Скрипт заберёт свежий код, проверит PHP и перезапустит PHP-FPM. `config.php`, база и загруженные PDF (`data/`) в git не хранятся и при обновлении не трогаются.

## Запуск

1. Откройте `https://visabot.b-integration.ru/admin/`, войдите.
2. **Промт** — подставьте название компании, поправьте стиль.
3. **Данные компании** — страны, цены, сроки, контакты, условия. Это главный источник.
4. **Материалы** — загрузите учебники, выгрузки, JSON. Большие файлы удобнее из консоли:
   `sudo -u www-data php bin/index.php /path/file.zip "Название"` (добавьте `--aux` для вспомогательного источника)
5. **Проверка** — задайте вопрос, посмотрите, какие фрагменты найдены и что ответил бот.
6. Виджет на сайт визового центра (и добавьте этот сайт в `allowed_origins`):
   ```html
   <script src="https://visabot.b-integration.ru/widget.js" data-title="Визовый консультант" data-color="#1f4e8c" defer></script>
   ```
7. Telegram: создайте бота у @BotFather, токен — в config.php, затем:
   ```bash
   curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
     -d "url=https://visabot.b-integration.ru/telegram.php" \
     -d "secret_token=<telegram_secret из config.php>"
   ```
   `/start` — приветствие, `/new` — новый диалог.
8. Вход через Telegram на сайте: впишите `telegram_bot_username` в config.php и у @BotFather
   выполните `/setdomain` → выберите бота → `visabot.b-integration.ru`. Без этого кнопка входа не появится / не сработает.

## Стоимость и настройки

- На каждый вопрос: 1 эмбеддинг вопроса (доли копейки) + запрос к модели с промтом, данными компании и ~6 фрагментами (≈ 3–5 тыс. токенов вместо всего учебника).
- Эмбеддинги учебника считаются один раз при загрузке.
- `use_embeddings => false` — только полнотекстовый поиск, без расходов на эмбеддинги, но хуже ловит перефразировки.
- `top_k`, `chunk_chars` — сколько и какого размера фрагменты подставлять.
- `chat_model` — любая модель чата из вашего аккаунта OpenAI. Модель должна поддерживать JSON-схему ответа (gpt-4o, gpt-4.1, gpt-5 и новее); если не поддерживает — бот ответит обычным текстом, а контакты будет ловить только по шаблону телефона.
- `openai_base_url` — если OpenAI не пускает запросы с сервера в РФ, укажите адрес своего прокси/шлюза с OpenAI-совместимым API.

## Важное

- Сканы PDF без текстового слоя не читаются — сначала распознайте (OCR), например `ocrmypdf in.pdf out.pdf`.
- Бот собирает персональные данные (имя, телефон). По 152-ФЗ нужна политика обработки ПД: укажите ссылку в `privacy_url`, она появится под чатом.
- Клиенты и диалоги хранятся в `data/bot.sqlite`.
- Бэкап — копия папки `data/`.
